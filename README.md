# Entre proches — maquette du site

Version de démonstration du site Entre proches (traiteur après obsèques), conçue par La Buon'Com.

- Site statique HTML / CSS / JS, publié avec GitHub Pages.
- **Démo uniquement** : les formulaires n'envoient rien (`DEMO = true` dans `assets/js/main.js`) et le site est exclu des moteurs de recherche (`noindex` + `robots.txt`).
